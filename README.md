# MediaHub Pro 

**MediaHub Pro** — це сучасна інформаційна система керування мультимедійним контентом (фільми, серіали, ігри) з елементами соціальної взаємодії та інтегрованою системою оцінювання. Проєкт розроблено як Single Page Application (SPA) з використанням асинхронного REST API на бекенді та преміального UI у стилістиці Apple на фронтенді.

---

##  Ключовий функціонал системи

* **Асинхронний REST API:** Високопродуктивний бекенд, побудований на FastAPI з асинхронними запитами до БД через SQLAlchemy.
* **Реляційна база даних:** Структура PostgreSQL зі складними реляційними зв'язками, індексацією та налаштованим **каскадним видаленням (Cascade Delete)**.
* **Безпека та Авторизація:** Повноцінна система реєстрації та аутентифікації користувачів за допомогою **JWT (JSON Web Tokens)** та безпечного хешування паролів (`bcrypt`).
* **Розумний каталог (Рівень IMDb):** Живий повнотекстовий пошук контенту (за назвою, акторами або жанром), гнучка фільтрація за типами мультимедіа та динамічне сортування (за рейтингом, роком випуску чи новизною).
* **Reddit-подібні Чат-кімнати:** Тематичні Reddit-кімнати для кожного релізу з можливістю обговорення та системою карми коментарів (**Upvote / Downvote**).
* **Інтелектуальні рекомендації:** Розумний алгоритм автоматичного підбору блоку "Тобі також може сподобатися" на основі перетину жанрів мультимедіа.
* **Особистий простір (Медіатека):** Індивідуальне збереження релізів, керування статусами перегляду/проходження ("В планах", "В процесі", "Завершено") та написання особистих рецензій.
* **Особистий кабінет:** Інтерактивна панель зі статистикою активності користувача та анімованими лічильниками.
* **Управління файлами:** Система динамічного завантаження обкладинок (постерів) та широких фонів з локального ПК на сервер.
* **Повна адаптивність (Mobile-First):** Преміальний UI на Tailwind CSS з ефектами розмиття (`backdrop-blur`), який ідеально масштабується як на моніторах 4K, так і на екранах мобільних телефонів.

---

## 🛠 Технологічний стек

* **Backend:** Python 3.11+, FastAPI, Pydantic v2, PyJWT, bcrypt.
* **Database & ORM:** PostgreSQL, SQLAlchemy (Asyncio), Greenlet.
* **Frontend:** HTML5, CSS3, Tailwind CSS, JavaScript (ES6, Fetch API), AOS (Animate On Scroll).

## 🚀 Інструкція із запуску (Локально)

1.  **Клонуйте репозиторій:**
    ```bash
    git clone [https://github.com/ТВІЙ_НІК/MediaHub-Diploma.git](https://github.com/ТВІЙ_НІК/MediaHub-Diploma.git)
    cd MediaHubDB
    ```
2.  **Налаштуйте віртуальне середовище:**
    ```bash
    python -m venv venv
    venv\Scripts\activate  # Windows
    source venv/bin/activate  # macOS/Linux
    ```
3.  **Встановіть залежності:**
    ```bash
    pip install fastapi uvicorn sqlalchemy asyncpg PyJWT bcrypt python-multipart jinja2
    ```
4.  **Запустіть сервер розробки:**
    ```bash
    uvicorn main:app --reload
    ```
5.  **Відкрийте додаток:**
    * Веб-інтерфейс: `http://127.0.0.1:8000`
    * Документація Swagger API: `http://127.0.0.1:8000/docs`
